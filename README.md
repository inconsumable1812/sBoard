# PixiJS → Skia Renderer

Демо: https://inconsumable1812.github.io/sBoard/

## Описание

Тестовое задание по реализации конвертации сцены PixiJS в рендеринг через Skia (CanvasKit) с последующим экспортом в PDF.

Стек:

- React
- TypeScript
- PixiJS
- CanvasKit (Skia WASM)

## Реализовано

### Отрисовка сцены через Skia

Реализован рекурсивный обход дерева PixiJS-сцены и отрисовка объектов через CanvasKit.

Поддерживаются:

- PIXI.Container
- PIXI.Graphics
- PIXI.Sprite
- вложенные контейнеры
- position
- scale
- rotation

Для рендеринга и экспорта используется рекурсивный обход дерева PixiJS-сцены.

### Экспорт в PDF

Реализован экспорт сцены в PDF на основе обхода дерева PixiJS.

Поддерживаются:

- Rectangle
- Ellipse
- Line

При экспорте сохраняются:

- цвета
- позиционирование
- масштабирование
- базовые трансформации объектов

## Архитектура

Проект разделён на независимые слои:

- PixiJS сцена
- Renderer Pixi → CanvasKit
- PDF Exporter

Для CanvasKit-рендеринга и PDF-экспорта используются схожие механизмы обхода дерева PixiJS-сцены.

## Ограничения

Текущая реализация поддерживает демонстрационный набор примитивов и не покрывает все возможности PixiJS:

- complex paths
- masks
- filters
- blend modes
- текст
- полную совместимость со всеми типами Graphics Geometry

Экспорт PDF реализован через `pdf-lib`.

Требование по кастомной WASM-сборке было исследовано отдельно. В ходе работы выяснилось, что стандартная npm-сборка canvaskit-wasm не содержит PDF API. Для реализации экспорта через Skia PDF backend требуется сборка собственной версии CanvasKit из исходников Skia. Такая задача затрагивает инфраструктуру сборки самого Skia и существенно выходит за рамки использования готового CanvasKit как браузерной библиотеки. В рамках тестового задания собственная WASM-сборка не была завершена, поэтому экспорт PDF реализован через pdf-lib с сохранением векторного представления базовых примитивов.
