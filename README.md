# PixiJS → Skia Renderer

Демо: https://inconsumable1812.github.io/sBoard/

## Описание

Тестовое задание по реализации конвертации сцены PixiJS в рендеринг через Skia (CanvasKit) с последующим экспортом в PDF.

Проект реализован на:

- React
- TypeScript
- PixiJS
- CanvasKit (Skia WASM)

## Реализовано

### Этап 1. Отрисовка сцены через Skia

Реализован обход дерева PixiJS-сцены с последующей отрисовкой объектов в CanvasKit.

Поддерживаются:

- PIXI.Container
- PIXI.Graphics
- PIXI.Sprite (bitmap)
- трансформации объектов:
  - position
  - scale
  - rotation
  - вложенные контейнеры

Для рендеринга используется рекурсивный обход дерева сцены.

### Этап 2. Экспорт в PDF

Реализован экспорт сцены в PDF, используется библиотека pdf-lib.

Поддерживается экспорт:

- прямоугольников
- эллипсов
- линий

## Почему не Skia PDF backend

В рамках тестового задания для реализации экспорта был использован pdf-lib, так как он:

- быстро интегрируется в браузерный pipeline
- не требует кастомной сборки Skia PDF WASM
- позволяет оперативно проверить корректность логики экспорта сцены

В текущей реализации экспорт выполняется на основе обхода PixiJS сцены и ручного преобразования примитивов в PDF-операции. Такой подход покрывает базовые кейсы (rect, ellipse, line, transform), включая учёт трансформаций (position / scale / rotation).

Поддержка Skia PDF backend архитектурно возможна в дальнейшем: логика обхода сцены уже отделена от конкретного формата вывода, поэтому PDF-рендерер может быть заменён на Skia CanvasKit PDF surface без изменения логики traversal.

## Ограничения текущей реализации:

- экспорт основан на упрощённой геометрической модели PixiJS Graphics
- не поддерживаются все особенности PixiJS (filters, blend modes, complex paths)
- PDF-вывод реализован через pdf-lib, а не через Skia PDF backend
